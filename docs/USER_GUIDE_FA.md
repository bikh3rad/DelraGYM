# راهنمای دلارا

دلارا یک اپلیکیشن کامل برای دنبال کردن تمرین‌ها و وزن بدن است. این راهنما به شما کمک می‌کند تا از تمام امکانات اپلیکیشن استفاده کنید.

---

## شروع سریع

### ۱. ورود به اپلیکیشن
- **ورود با کلید عبور (Passkey):** اگر قبلاً حساب کاربری ساخته‌اید
- **ساخت پروفایل جدید:** برای کاربران جدید
- **ادامه بدون حساب کاربری:** اگر فقط می‌خواهید امتحان کنید (داده‌ها فقط در مرورگر شما می‌مانند)

### ۲. ساخت برنامه تمرینی
پس از ورود، اگر هنوز برنامه‌ای ندارید، یک کارت خوشامد می‌بینید با دو گزینه:
- **بارگذاری برنامه آغازین:** برنامه‌های آماده مثل Push/Pull/Legs، Upper/Lower، Full Body یا 5×5
- **ساخت برنامه خودم:** برنامه شخصی خود را بسازید

## تب‌های اصلی

### 🏠 خانه (Home)
- تاریخ امروز و روزهای هفته را نشان می‌دهد
- تمرین امروز را شروع کنید با کلیک روی «شروع»
- وزن بدن خود را ثبت کنید
- اگر برنامه‌ای ندارید، پیشنهاد ساخت برنامه می‌بینید

### 📅 برنامه (Plan)
- برنامه هفتگی خود را تعریف کنید
- برای هر روز هفته یک برنامه (روتین) انتخاب کنید
- یا از حالت «چرخش» استفاده کنید (A، B، C، A، ...)
- با کلیک روی هر روز، برنامه‌ها را اضافه یا تغییر دهید

### ▶️ شروع (Start)
- تمرین امروز را شروع کنید
- تمرین آزاد (Freestyle) بدون برنامه از قبل
- انتخاب تمرین دیگر

### 📊 آمار (Stats)
- نقشه حرارتی فعالیت ۱۲ ماه گذشته
- نمودار وزن بدن با هدف
- پیشرفت هر حرکت
- رکوردهای شخصی (PR)
- تعادل عضلانی

### 💪 حرکات (Library)
- مرور ۵۶۰۰+ حرکت با تصویر و انیمیشن
- جست‌وجو بر اساس نام یا عضله
- فیلتر بر اساس نوع و تجهیزات
- **تگ خانه/باشگاه:**
  - **خانه و باشگاه:** حرکاتی که هم در خانه و هم در باشگاه قابل انجام هستند
  - **فقط باشگاه:** حرکاتی که به تجهیزات باشگاه نیاز دارند
- با کلیک روی هر حرکت، تصویر، توضیحات و روش انجام را می‌بینید

### ⚙️ تنظیمات (Settings)
- **تمرین:** تنظیمات تایمر استراحت، نمایش، صدا
- **هشدارهای تایمر:** صدا، لرزش، فلش
- **یادآوری‌ها:** اعلان‌های روزانه
- **برنامه و زمان‌بندی:** نوع هفته (ثابت/چرخش)، شروع هفته (شنبه)
- **واحدها:** کیلوگرم/پوند (فارسی تنها زبان)
- **تجهیزات:** پروفایل تجهیزات خود را بسازید
- **ظاهر و خانه:** تم روشن/تاریک، رنگ تأکیدی
- **داده و پشتیبان:** وارد/خارج کردن داده‌ها

## جریان کاری روزانه

### ۱. ورود به خانه
صفحه خانه تاریخ امروز و تمرین برنامه‌ریزی شده را نشان می‌دهد.

### ۲. وزن‌کشی (اختیاری)
قبل از شروع تمرین، وزن خود را ثبت کنید تا نمودار وزن بدن به‌روز شود.

### ۳. شروع تمرین
- روی «شروع» بزنید تا تمرین امروز آغاز شود
- وزنه‌ها از دفعه قبل خودکار پر می‌شوند
- تایمر استراحت بین ست‌ها اجرا می‌شود
- رکوردهای شخصی در حین تمرین شناسایی می‌شوند

### ۴. در حین تمرین
- هر ست را ثبت کنید
- با کشیدن انگشت به چپ، ست را حذف کنید
- با کشیدن به راست، ست را کپی کنید
- روش انجام هر حرکت را با کلیک روی آیکون ببینید

### ۵. پایان تمرین
- خلاصه تمرین: تعداد ست‌ها، حجم کل، رکوردهای جدید
- تمرین در تاریخچه ذخیره می‌شود

## حرکات: خانه vs باشگاه

هر حرکت یکی از این تگ‌ها را دارد:

| تگ | معنی |
|-----|------|
| 🏠 **خانه و باشگاه** | با وزن بدن، دمبل، کتل‌بل، کش یا تو پزشکی — قابل انجام در خانه |
| 🏋️ **فقط باشگاه** | به هالتر، کابل، دستگاه یا تجهیزات باشگاه نیاز دارد |

### فیلتر کردن
در تب حرکات، می‌توانید فیلتر کنید:
- **بدون تجهیزات:** حرکات با وزن بدن (مناسب خانه)
- **دمبل / هالتر / کابل / ...:** بر اساس تجهیزات موجود

| برنامه | توضیح |
|--------|-------|
| **Push/Pull/Legs** | ۳ روز: فشار (سینه/شانه)، کشش (پشت/جلوبازو)، پا |

| **Full Body** | ۳ روز: تمام بدن در هر جلسه |
| **5×5** | قدرت: ۵ ست × ۵ تکرار با وزنه سنگین |

## نصب و اجرا

### با Docker (ساده‌ترین)
```bash
# فایل .env بسازید
cat > .env << 'EOF'
RP_ID=localhost
ORIGIN=http://localhost:8080
WEB_PORT=8080
RP_NAME=دلارا
PORT=3000
DEFAULT_LANG=fa
TRUST_PROXY=1
EOF

# اجرا
docker compose up --build
```
مرورگر: `http://localhost:8080`

### ساخت APK اندروید با Docker
```bash
bash scripts/build-apk.sh
# خروجی: output/delara-debug.apk
```

### اجرای frontend به‌تنهایی
```bash
cd frontend
npm install
npm run dev
# مرورگر: http://localhost:5173
```

## نکات کاربردی

### 🔥 برای تمرین در خانه
1. در تب حرکات، فیلتر «بدون تجهیزات» را انتخاب کنید
2. حرکات با تگ «خانه و باشگاه» را پیدا کنید
3. یک برنامه ساده مثل Full Body بسازید

### 📈 برای پیشرفت
1. هر تمرین را ثبت کنید تا نمودار پیشرفت ساخته شود
2. وزنه‌ها را از دفعه قبل به‌روز کنید
3. هفته‌ای یک‌بار وزن بدن را ثبت کنید
4. در تب آمار، نقشه حرارتی را بررسی کنید

### 🔄 همگام‌سازی
- با ساخت حساب کاربری، داده‌های شما بین دستگاه‌ها همگام می‌شود
- در تنظیمات → داده و پشتیبان، می‌توانید پشتیبان بگیرید
